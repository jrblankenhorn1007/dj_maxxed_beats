## Decision — verify the exact platform-specific loader entry point

- **Context:** The smoke script previously assumed Darwin `nm -gU` and
  `_load` on every platform. ELF and Windows x64 use GNU `nm` options and
  the unprefixed `load` export.
- **Decision:** Use Darwin `nm -gU` / `_load` or ELF and Windows x64
  `nm -g --defined-only` / `load`; require the exact global defined text
  symbol, normalize Windows CRLF, report `nm` command failures, and preserve
  the warning-and-skip behavior when `nm` is absent. Add network-free mocks
  for Darwin, ELF, Windows x64/CRLF, similar and undefined names, command
  failure, and missing `nm`; accept only the exact `_load` or `load` NRT
  verification line.
