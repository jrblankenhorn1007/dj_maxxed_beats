# Code review archive

Record `NOT_APPLICABLE` for an integration path that has no PR. For a PR,
record the full base and head SHAs, PR URL, reviewer agent names/roles,
round number, task-specific reviewer prompt, structured report and findings,
and the author's action/rationale in `round-01.md` and, only when needed,
`round-02.md`.

The initial pass is round 1; at most one follow-up is allowed. After round 2,
the author acts on that report alone and no third reviewer pass is dispatched.
Use the canonical Ralph PR Review skill for the exact gate. Keep reports as
sidecar evidence while the PR is open and archive them here after integration
so the reviewed PR's head/base is not changed by the report itself.

For historical work, use `LEGACY_NOT_ARCHIVED` if this repository has no
report. That label does not assert that no review occurred elsewhere.
